# コードのコメントの心得

コメントを書く時と、コードを消す時は、以下の基準に従う。

## 心得1. コメントには今の状態だけを書く

コメントは、今のコードが何をしていて、なぜそうなっているかを説明するために書く。変更の経緯は書かない。

- コードを消した時、外した時に「確認できたので撤去した」「アーカイブしたので外した」のようなコメントを残さない。後から読む人が必要としない情報である
- 経緯はcommit messageとPR概要欄に書く

## 心得2. 消す時はコメントごと消す

コードや設定を消す時は、それに付いていたコメントも行ごと消す。「撤去した」と書き換えて残さない。

消したファイルや設定を参照している別の場所のコメントも探して直す。「考え方はXと同じ」のように、消した物を前提にした説明は、消した後に意味が通らなくなる。
